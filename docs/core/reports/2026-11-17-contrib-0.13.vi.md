### serve --watch (nhánh `integrate/serve-watch`)

- Viết lại theo thiết kế v3 (`docs/core/plans/serve-watch.md`, 3 vòng Codex trước khi code): chỉ CLI, không đổi Core; Unix (Windows báo chưa hỗ trợ).
- `cargo build` kiểm mọi thay đổi khi server cũ vẫn chạy; build lỗi giữ server; chạy server qua `cargo run` (giữ `[env]` của Cargo); build và server ở process group riêng, Ctrl-C dọn cả hai (6 s rồi SIGKILL); thay đổi trong lúc build không bị mất; template tự nạp lại và source extension không kích hoạt build (nhắc `npm run build`); đổi manifest thì đọc lại package/binary; manifest lỗi thì giữ server.
- Dependency: `tokio` (workspace) + `nix =0.31.3` (đã có trong lock) — workspace cấm `unsafe`.
- Codex review code 2 vòng: 9 + 6 phát hiện, đã sửa hết.
- **Lỗi chỉ thấy khi chạy thật**: `cargo metadata` của workspace lớn hơn bộ đệm pipe → watcher treo. Sửa: ghi ra file tạm; test giả lập nay xuất 200 KB.
- Test: 8 unit + 3 tích hợp (cargo giả: build lỗi giữ server, build tốt thay server, Ctrl-C giữa build/khi chạy không sót tiến trình, manifest lỗi); kiểm tra ngược (bỏ process group → fail; dùng pipe → fail). Chạy thật trên demo: sửa `src/main.rs` → build 3,7 s → thay server; sửa template → không build; Ctrl-C → không còn tiến trình.
