### Mốc B — `shown_when` + `title_template`

- Cherry-pick 0c3d9fd (giữ tác giả); xung đột CHANGELOG giải tay (bỏ dòng watch).
- Thiết kế sửa qua Codex (`contrib-0.13-b.md`), Codex bắt thêm 7 điểm → đã đưa vào.
- Sửa chính:
  - Điều kiện tính trên **những gì form của người dùng có** (giống hệt SPA): trường không đọc được, bản ghi không xem được (blind write), ô write-only → coi như rỗng. Kết quả lưu/bỏ/required/xoá không còn lộ gì về trường bị che.
  - Khoá ngoại do trang quan hệ gắn: không bao giờ bị bỏ (hết lỗi 500); SPA giữ nó làm ô ẩn bị khoá để tính điều kiện giống server.
  - `clear_when_hidden` **chỉ xoá khi chính lần ghi làm ô bị ẩn** (đổi so với bản gốc): nếu không, người không thấy trường điều kiện sẽ xoá dữ liệu mỗi lần sửa. Ghi trong ADR 0037, guide, CHANGELOG.
  - Required/không-null khi hiện: gửi `null`, lúc tạo, hoặc lần ghi làm hiện ô.
  - Settings: `kept_while` và kiểm media dùng giá trị cuối cùng (gồm reset của ô ẩn) → mật khẩu bị xoá khi host bị reset.
  - Schema gửi literal điều kiện đã chuẩn hoá; SPA chuẩn hoá UUID (`{…}`, `urn:uuid:`, 32 hex).
  - Tab giữ theo vị trí khai báo.
  - Tìm kiếm: bỏ từ trùng (không cắt số từ).
- Test mới: `condition_access.rs` (4 kịch bản lộ dữ liệu/blind/khoá ràng buộc/null), relay settings, fixture UUID, vitest tab + khoá ràng buộc, kitchen-sink contract có `shownWhen`. Kiểm tra ngược: bỏ sửa → 5 test server + 2 test SPA fail.
- Docs: ADR 0037 (mục "Values the conditions read"), ADR 0038 (tìm kiếm), guide forms, CHANGELOG, upgrade "From 0.12.1 to 0.13.0".

### serve --watch (nhánh `integrate/serve-watch`)

- Viết lại theo thiết kế v3 (`docs/core/plans/serve-watch.md`, 3 vòng Codex trước khi code): chỉ CLI, không đổi Core; Unix (Windows báo chưa hỗ trợ).
- `cargo build` kiểm mọi thay đổi khi server cũ vẫn chạy; build lỗi giữ server; chạy server qua `cargo run` (giữ `[env]` của Cargo); build và server ở process group riêng, Ctrl-C dọn cả hai (6 s rồi SIGKILL); thay đổi trong lúc build không bị mất; template tự nạp lại và source extension không kích hoạt build (nhắc `npm run build`); đổi manifest thì đọc lại package/binary; manifest lỗi thì giữ server.
- Dependency: `tokio` (workspace) + `nix =0.31.3` (đã có trong lock) — workspace cấm `unsafe`.
- Codex review code 2 vòng: 9 + 6 phát hiện, đã sửa hết.
- **Lỗi chỉ thấy khi chạy thật**: `cargo metadata` của workspace lớn hơn bộ đệm pipe → watcher treo. Sửa: ghi ra file tạm; test giả lập nay xuất 200 KB.
- Test: 8 unit + 3 tích hợp (cargo giả: build lỗi giữ server, build tốt thay server, Ctrl-C giữa build/khi chạy không sót tiến trình, manifest lỗi); kiểm tra ngược (bỏ process group → fail; dùng pipe → fail). Chạy thật trên demo: sửa `src/main.rs` → build 3,7 s → thay server; sửa template → không build; Ctrl-C → không còn tiến trình.
